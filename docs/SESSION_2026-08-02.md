## 3. The audit (what the 6 auditors found)
Full write-up: [`research/learning/11-audit-and-reality.md`](../research/learning/11-audit-and-reality.md).
The **engineering was real** (atomic wedge, schema, guardrails, least-privilege IAM — all verified).
Problems clustered as:
- **Real bugs the fake runtime hid:** consolidation memory-poisoning (a *failed* episode could mint a
  "success" runbook), non-idempotent remediation, `semantic_current` not unique, runbook status not
  checked, no recall retry, unguarded model-output parsing, infra errors mislabeled 409, unbounded
  event history, no Bedrock timeouts.
- **Security gaps:** approval gate trusted a **model-controlled flag**; recalled memory unscreened; the
  "non-bypassable" provenance wrapper was dead code; role-scoping cosmetic under one DSN.
- **Infra:** a CloudTrail-key grant that would fail `cdk deploy`; a PrivateLink SG with no ingress.
- **Rigged metrics** (§2).

## 5. The rebuilt frontend
The old console was cluttered and unreadable. Rebuilt from scratch in two waves on the **honest data
layer** (`web/lib/*.ts` mappers were kept — they're the de-rigged contracts):
- **Design system** (`web/components/ui/`, documented in `ui/README.md`): a calm "flight-recorder"
  identity — iris accent + reserved gold=memory / cyan=action / coral=region-kill; full light+dark
  tokens; no-flash theme toggle; mono tabular figures; and the Reality-Charter grammar **solid =
  measured, dashed = pending**.
- **Bespoke SVG charts** (`web/components/charts/`, no chart library — unit-tested geometry,
  dataviz-validated palette): ranked bars, radial gauge, node-liveness step-timeline w/ outage band,
  status grid, region topology, leaseholder stacks, incident station-rail, drift validity timeline.
- **Four focused views** (`web/components/views/`): **Overview** (proven-vs-pending board), **Incident**
  (perceive→recall→reason→act→record + one-txn envelope), **Resilience** (real failover: RTO/RPO,
  liveness, region map, probes), **Memory & Retrieval** (recall@k + nDCG + hard-negatives explainer +
  drift timeline + honest MTTR-pending panel).
